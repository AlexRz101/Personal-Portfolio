# Personal Portfolio

A **Cyberpunk 2077-inspired personal portfolio website** showcasing my projects, background, and contact information.

## Features

* Cyberpunk-inspired visual design and styling
* Responsive layout for desktop and mobile devices
* Dedicated pages for projects, about me and contact information
* Custom visuals and neon-inspired aesthetics

## Tech Stack

* React
* TypeScript
* Tailwind CSS
